## Next Gen gates

For the Next Gen Award:

- Entrant must be an active student enrolled in a qualifying academic program.
- A qualifying student or academic email is required on Devpost; domain eligibility may be checked using JetBrains/swot.
- The project must be an iOS/iPadOS/macOS/Android software application that uses RevenueCat for a purchase/monetization flow (or RevenueCat Ads where applicable).
- Instead of an app-store listing, Next Gen requires a **public open-source repository** with source, assets, instructions, and an open-source license that GitHub can detect.
- The demo must be publicly visible on YouTube or Vimeo and should be **under two minutes**; judges are not required to watch beyond two minutes.
- The video should show the project functioning on the device/platform for which it was built.
- Next Gen is exempt from the store-download testing requirements and does **not** require a paid Apple/Google developer account or store release.
- An official Shipaton manager has explicitly confirmed that **RevenueCat Test Store is sufficient for Next Gen**.

## Next Gen judging criteria

The current official criteria ask whether:

1. the app idea is clear, useful, interesting, or original and creates a compelling experience or solves a real problem;
2. the project shows meaningful progress toward a working app and makes the core functionality clear in the video and code repository;
3. RevenueCat is used thoughtfully for the monetization flow; and
4. the submission demonstrates thoughtful technical choices, product thinking, and care in build/presentation.
